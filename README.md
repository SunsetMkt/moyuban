# 摸鱼办

一个集成各种工具的在线网站。

## 在线地址

[https://moyu.awsl.icu](https://moyu.awsl.icu)

## 技术栈

- **前端**: React 19 + TypeScript + Tailwind CSS v4
- **后端**: FastAPI + Python
- **部署**: Vercel + PWA

## 功能

- 📅 摸鱼日历
- 🛠️ 实用工具集（密码生成、URL/Base64 编码解码、内容分享）
- 📊 进度追踪（今日/本周/本月/本年）
- 📱 PWA 支持，可添加到桌面

## API

API 文档: [https://moyu.awsl.icu/docs](https://moyu.awsl.icu/docs)
