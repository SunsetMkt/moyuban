# 摸鱼办前端

一个集成各种工具的在线网站。

## 技术栈

- React 19 + TypeScript
- React Router v7
- Tailwind CSS v4
- shadcn/ui (Radix UI)
- Zustand 状态管理
- Vite 构建工具
- PWA 支持

## 开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 预览生产版本
pnpm preview

# 代码检查
pnpm lint
```

## 功能

- 首页：摸鱼日历
- 工具集：密码生成、URL/Base64 编码解码、内容分享
- 进度：今日、本周、本月、本年进度查看
- 关于：项目介绍
